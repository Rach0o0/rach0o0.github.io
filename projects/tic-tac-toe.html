Tic-Tac-Toe Multiplayer in C

This is a multiplayer tic-tac-toe client & server implementation in C

Description

This project implements a multiplayer Tic Tac Toe game in C, based on a client-server architecture over UDP. Project done with Ayoub Agouzoul.

Key Features

  • Supports multiple games in parallel using multithreading with pthread
  • The server manages client matchmaking and game logic
  • Each client communicates with the server to send and receive moves
  • Includes synchronization mechanisms (mutexes, condition variables) to ensure correct and concurrent gameplay
