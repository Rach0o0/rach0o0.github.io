2D Platformer Game – Grottescape

Description

This is a 2D platformer game created entirely from scratch using HTML, CSS, and JavaScript.

Key Features

  • Custom physics engine with gravity and collision detection
  • A responsive player character with animations
  • Multiple playable levels defined through configuration files
  • A clean and modular JavaScript codebase for future expansion
  • The game showcases fundamental principles of game development in a web environment, using only front-end technologies
