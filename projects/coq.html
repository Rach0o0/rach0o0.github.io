Coq Project

Propositional Logic

Description

This project explores propositional logic using Coq. We define logical formulas, their semantics, and a natural deduction system. The goal is to prove that this system is sound and that it’s possible to decide whether a formula is valid. In the second part, we implement a decision procedure to automatically check if a formula is a tautology, using normalization. Project done with Ayoub Agouzoul.
